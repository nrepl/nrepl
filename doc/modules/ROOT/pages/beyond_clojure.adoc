= Beyond Clojure
:description: nREPL servers and clients for languages other than Clojure.

As mentioned earlier the nREPL protocol is language-agnostic and can
be leveraged for many languages that have the ability to evaluate code
at runtime.

== Alternative Server Implementations

Most of those server implementations are developed and
maintained by third-parties (as opposed to nREPL's team), and their
maturity might vary. The ones from nREPL's team are marked as such.

NOTE: Certain nREPL clients may make Clojure-specific assumptions which
will cause bugs when used with other servers, while other clients are
designed with language-agnosticism in mind. Usually the nREPL servers would mention in their
documentation which clients are known to work well with them.

TIP: nREPL's compatibility suite, https://github.com/nrepl/proof[proof], checks
servers against the clients people use, and its
https://nrepl.github.io/proof/[compatibility matrix] shows how a number of
servers do.

* https://gitlab.com/technomancy/jeejah[JeeJah] - an nREPL server for https://fennel-lang.org/[Fennel] and https://www.lua.org/[Lua]

* https://gitlab.com/technomancy/ogion[Ogion] - an nREPL server for https://racket-lang.org/[Racket]

* https://github.com/sjl/cl-nrepl[cl-nrepl] - an nREPL server for Common Lisp

* https://git.sr.ht/~ngraves/nrepl-python[nrepl-python] - an nREPL server for https://www.python.org/[Python]

* https://github.com/babashka/babashka.nrepl[Babashka nREPL] - an nREPL server bundled with https://github.com/borkdude/babashka[babashka]

* https://github.com/djblue/nrepl-cljs[nrepl-cljs] - a native ClojureScript nREPL server implementation

* https://github.com/viesti/nrepl-cljs-sci[nrepl-cljs-sci] - a native Node.js nREPL server implementation using https://github.com/borkdude/sci[SCI].

* https://github.com/babashka/nbb[nbb] - Clojure scripting on Node.js using SCI, with an nREPL server built in

* https://github.com/babashka/sci.nrepl[sci.nrepl] - the nREPL server of https://github.com/babashka/scittle[scittle], which runs SCI in the browser, connected to clients through a websocket relay that runs on babashka or the JVM

* https://github.com/nrepl/nrepl-sci[nrepl-sci] - an nREPL server for SCI that runs in a web page, developed by nREPL's team

* https://github.com/basilisp-lang/basilisp[Basilisp] - a Clojure-compatible(-ish) Lisp dialect hosted on Python, with an nREPL server built in

* https://github.com/clojure/clr.tools.nrepl[clr.tools.nrepl] - an nREPL server for https://github.com/clojure/clojure-clr[ClojureCLR]

* https://github.com/jank-lang/jank[jank] - a native Clojure dialect with C++ interop, with an nREPL server built in

* https://github.com/nooga/let-go[let-go] - almost Clojure, written in Go, with an nREPL server built in

* https://git.sr.ht/~abcdw/guile-ares-rs[guile-ares-rs] - an Asynchronous Reliable Extensible Sleek RPC Server for Guile based on the nREPL protocol.

* https://git.sr.ht/~ngraves/nrepl-scilab[nrepl-scilab] - an nREPL server for https://www.scilab.org/[Scilab]

* https://github.com/waddie/nrepl-janet[nrepl-janet] - an nREPL client/server library for https://janet-lang.org/[Janet]

* https://github.com/waddie/nrepl-steel[nrepl-steel] - a minimal nREPL server for https://github.com/mattwparas/steel[Steel Scheme]

* https://github.com/nrepl/nrepl-beam[nrepl-beam] - nREPL servers for https://www.erlang.org/[Erlang] (dialtone) and https://elixir-lang.org/[Elixir] (repartee), developed by nREPL's team

As you can see nREPL has implementations for many popular Lisp dialects, but it's certainly not limited to Lisp dialects.
